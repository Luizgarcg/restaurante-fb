# Template Base - Bar e Restaurante

Modelo de landing page responsiva desenvolvido para estabelecimentos do segmento de gastronomia e entretenimento. O projeto serve como estrutura base para rápida personalização e implantação.

## Funcionalidades

- Menu hambúrguer adaptado para navegação em dispositivos móveis.
- Carrossel interativo para exibição de produtos e destaques do cardápio.
- Alternância dinâmica de mapas entre diferentes unidades sem recarregar a página.
- Formulário de reserva com validação de dados e envio direto para o WhatsApp.

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla)
